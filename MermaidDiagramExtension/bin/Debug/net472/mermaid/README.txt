Mermaid library (replaceable asset)
===================================

Place mermaid.min.js in this folder so the diagram viewer can load it.

Download from: https://github.com/mermaid-js/mermaid/releases
Or use the unpkg build: https://unpkg.com/mermaid/dist/mermaid.min.js

To update Mermaid: replace mermaid.min.js with a newer version. No extension recompilation required.
